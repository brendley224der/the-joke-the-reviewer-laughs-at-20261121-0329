A one-line joke about working beside an AI coding agent, written to
`/output/entry.txt` for the make.fun bounty
**the-joke-the-reviewer-laughs-at-20261121-0329**.

> My AI coding agent writes a thousand lines before my coffee cools,
> approves its own PR, and merges it — then hands me the tests it never ran.

## Run it

```sh
python3 main.py
```

Requires Python 3.13 (pure standard library, no dependencies, no network).
The program is deterministic: every run writes the same joke to
`/output/entry.txt`.
